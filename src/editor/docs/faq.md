# 常见问题

## 面板里没有我的脚本区块

按顺序排查：

1. 脚本挂到对象上了吗？属性检查器底部「添加脚本」→ 选你的脚本。
2. 脚本编译通过了吗？编译失败会在区块位置显示红字「编译失败：…」，脚本编辑器右上角也有语法检查结果。
3. 字段是不是都被 `@Hidden()` 了？全隐藏的组件只剩标题。

## 改了代码没有生效

- 代码编辑框里的改动要**提交**：点「保存」或点出编辑区（失焦提交）。
- 保存后属性面板会立刻重建，播放中需要停止再播放——运行中的实例不会热替换字段。
- 如果面板还显示旧字段：检查右上角是否红字报错，编译失败时代码不会生效。

## 编辑时看不到效果

编辑态只跑 `onMount` 和 `onFieldChange`。`onStart` / `onUpdate` 只在点 ▶ 播放后执行。
想在编辑时就能看见，把逻辑写进 `onFieldChange`（面板改值时触发），或者干脆先播放看。

## 字段值没保存下来

- 字段值必须能 JSON 序列化。函数、three 对象、DOM 节点、`Map` / `Set` 都存不住，
  这类东西用 `@Hidden()` 标成内部字段，运行时按需重建。
- 只存「被改过」的值：没动过的字段不写进工程文件，下次打开用脚本里的默认值。

## 脚本里为什么不能 import

组件脚本是单个源码文件，由编辑器现场编译成 CommonJS 再求值，`require` 被显式禁用。
需要的 API 都已经注入到作用域：

- 类和装饰器：`LightComponent` `Component` `Group` `Label` `Hint` `Order` `Hidden`
  `Num` `Int` `Bool` `Str` `Text` `Color` `Enum` `Asset` `Json` `List` `Panel`
- 事件总线：`Event`
- three：走 `this.three`

## `this.object3d` 是 null

视口还没初始化时（打开工程的头几帧）拿不到锚点。判空即可：

```ts
onStart() {
  const obj = this.object3d;
  if (!obj) return;             // 这次没拿到，下次播放再来
}
```

如果一直为 null，说明这个对象类型没有场景锚点（比如纯 UI 元素），检查 `node.kind`。

## 事件收不到

1. 是不是在**播放态**？`onEvent` 只在播放时派发。
2. 事件名完全一致吗？区分大小写，包括前缀。
3. 发送方用的是 `this.emit` / `Event.emit` 吗？`Event.on` 的订阅和 `onEvent` 是两条路，都能收到。
4. 发送方是钩子脚本吗？`Light.emit` 只发给钩子脚本，组件脚本收不到（反之亦然）。

## 能直接改别的对象吗

不能。`this.project` 是只读快照，`this.node` 只有自己。

正确姿势：广播事件，让目标对象自己的组件去改自己。

```ts
// A 脚本
this.emit('world:rain', { wet: true });

// B 脚本（挂在需要响应的对象上）
onEvent(type, payload) {
  if (type === 'world:rain' && payload?.wet) this.setNode({ minimapShow: false });
}
```

## 系统脚本改坏了怎么办

内置脚本是工程里的真实资产，改坏了不会自动还原。两种恢复方式：

1. 照「参考 · 内置组件脚本」里的源码片段改回去。
2. 删掉这个脚本资产，重新打开工程——缺失的系统脚本会按内置源码重建（**你改过的内容会丢**）。

## 每帧写 `setNode` 会怎样

每次写入都会进撤销历史并标记工程未保存。`onUpdate` 里每帧写一次，几十帧后撤销栈就被刷满了，
保存也会变得很吵。持续变化的表现（缩放、旋转、灯光明暗）直接改 three 对象；只有「用户应该
保存下来」的数据才走 `setNode`。

## 脚本能把编辑器弄崩吗

能。组件脚本不受沙箱保护，跑在主线程：

- `while (true) {}` 会卡死整个界面；
- 无限递归 / 每帧 `new` 大量对象会吃满内存；
- 改坏 `this.scene` 的全局属性（雾、背景）会影响整个视口。

写的时候先小步验证，复杂逻辑先在小场景里试。
