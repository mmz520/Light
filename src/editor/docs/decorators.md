# 显示控制注解

这些注解决定「字段在属性面板里怎么露出来」：哪个区块、叫什么、排第几、要不要隐藏。

| 注解 | 参数 | 作用 |
| --- | --- | --- |
| `@Component(name, opts)` | 名字 + `{ icon, order, desc }` | 类注解。面板里这个脚本区块的标题 / 图标 / 顺序 / 说明 |
| `@Group(name, order)` | 分组名 + 权重 | 字段归到哪个折叠标题下，权重小的组在前 |
| `@Label(text)` | 中文名 | 字段左侧的标签 |
| `@Hint(text)` | 说明文字 | 字段下方的小灰字 |
| `@Order(n)` | 权重 | 同一组内的排序，小的在前 |
| `@Hidden()` | — | 面板里不显示，但运行时照常可用 |

## 排序规则

1. 组按 `@Group` 的第二个参数（`groupOrder`）从小到大排；没写就是 100。
2. 组内按 `@Order` 从小到大排；没写就按字段在类里的声明顺序。
3. `@Component` 的 `order` 决定多个组件脚本在面板里的先后。

## 完整示例

```ts
@Component('篝火', { icon: '🔥', order: 35, desc: '照亮范围与燃料消耗' })
export default class CampfireComponent extends LightComponent {
  // 组「火焰」，权重 10：排在「燃料」前面
  @Group('火焰', 10) @Label('亮度') @Num(0, 8, 0.1) @Order(1) brightness = 2;
  @Group('火焰', 10) @Label('光圈半径') @Num(0.5, 12, 0.1) @Order(2) radius = 3;
  @Group('火焰', 10) @Label('火苗颜色') @Color() @Order(3) color = '#ff9a3c';

  // 组「燃料」，权重 20
  @Group('燃料', 20) @Label('剩余燃料') @Num(0, 600, 1) fuel = 120;
  @Group('燃料', 20) @Label('燃烧速率') @Num(0, 10, 0.1) burnRate = 1;

  // 内部状态：不用给用户看，但要能被保存 / 读回
  @Hidden() flicker = 0;
}
```

面板里会呈现为：

```
🔥 篝火
  火焰
    亮度        [ 2.0 ]
    光圈半径     [ 3.0 ]
    火苗颜色     [ ■ ]
  燃料
    剩余燃料     [ 120 ]
    燃烧速率     [ 1.0 ]
```

## 约定与坑

- 多个注解叠在同一行时顺序随意，装饰器是逐个累加属性的，先写 `@Group` 还是 `@Label` 结果一样。
- `@Hidden()` 只影响显示，字段值仍会随工程保存；想连保存都不要，用普通私有字段（不加任何注解）。
- 没有加任何控件注解的字段也会按默认值推断出控件（见「控件注解」），所以「不写注解 = 不显示」这个印象是错的。
- 字段名建议用英文 + 小驼峰；`@Label` 写中文。
