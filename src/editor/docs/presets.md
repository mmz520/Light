# 内置组件脚本

这些脚本是**系统自带**的：打开工程时自动创建，按对象类型自动挂到节点上，不需要手动添加。

- 面板里带「系统」徽章，不能从对象上卸载（✕ 按钮不显示）。
- 开发环境（桌面版）可以点「编辑」看源码、改字段、改逻辑；浏览器预览里只读。
- 资产浏览器里归在「系统脚本」虚拟目录，不能拖拽、不能删除。
- 判断依据是脚本资产的 `preset` 字段，改名不影响挂载关系。

## 清单

| --- | --- | --- | --- |
| 摄像机 | 🎥 | 摄像机 | 45 度角、距离、缓动跟随、跟随速度 |
| 变换 | ✥ | 分组 / 地皮 / 遮挡 / 敌人 / 角色 / 摄像机 | 位置 X、位置 Z（0.5 网格） |
| 角色 | 👤 | 角色 | 角色名、默认动画、状态机、控制器（多选）、血量、饥饿、理智、移速、攻击 |

| 地图元素 | 🧭 | 地图元素 | 屏幕 X / Y、形状、显示范围、框大小、装饰贴图 |

## 摄像机

场景里放一个「摄像机」对象（右键 → 新增 → 摄像机），它会自动挂上系统脚本「摄像机」，
点 ▶ 播放后接管视口相机：

| 字段 | 作用 |
| --- | --- |
| 45 度角 | 开 = 斜 45° 俯视（经典 ARPG）；关 = 接近垂直俯视（83°，完全 90° 会万向锁） |
| 距离 | 相机到角色的距离；`0` = 按角色身高自动算出「角色占屏幕约 1/3」的距离 |
| 缓动跟随 | 开 = 角色起步 / 停下都有缓冲过程；关 = 每帧硬贴角色 |
| 跟随速度 | 缓动强度，越大越跟手（1 ≈ 慢半拍，8 ≈ 几乎贴住）；关闭缓动时无效 |

缓动用的是指数阻尼 `1 - exp(-speed·dt)`：不管帧率多少，位移都会收敛到同一个锚点，
所以「停下后最终停的位置」和硬跟随完全一致，只是中间多了一段过渡。

场景里有多个摄像机时，只有**场景顺序第一个**会生效（它先抢到控制权，见「运行时 API · 摄像机」）。
没有摄像机对象时，运行时用内置的默认相机（45°、居中跟随），行为和以前一致。

## 它们和你自己的脚本是同一套机制

系统脚本不是硬编码在界面里的，就是普通的 `ScriptAsset`（`preset` 有值），用同样的
`LightComponent` + 装饰器 + 编译流程。所以可以照着它们的写法改：

```ts
// 变换（系统脚本，节选）
@Component('变换', { icon: '✥', order: 10 })
export default class TransformComponent extends LightComponent {
  @Group('位置', 10) @Label('位置 X') @Num(undefined, undefined, 0.5) x = 0;
  @Group('位置', 10) @Label('位置 Z') @Num(undefined, undefined, 0.5) z = 0;

  onMount() {
    this.x = this.node.x;
    this.z = this.node.z;
  }

  onFieldChange(key: string, value: any) {
    if (key === 'x' || key === 'z') this.setNode({ [key]: Number(value) || 0 });
  }
}
```

## 想自己改系统脚本？

1. 开发环境里在属性面板点「编辑」，或在资产浏览器的「系统脚本」里双击。
2. 改完保存，属性面板与播放立刻用新代码（按源码缓存，改了才重编译）。
3. 想保留原版，另存一份自己的脚本：把 `@Component` 名字改掉，从面板「添加脚本」挂到对象上。

> 不要改 `preset` 字段，也不要改脚本资产的 id：挂载关系靠它维持，改了会被判为「失效组件」而丢弃。
