## 修 bug：资源浏览器左栏看不到「脚本」文件夹

- 根因：`src/editor/model/folders.ts` 的 `KIND_ORDER` 漏了 `'script'`。AssetBrowser 的左栏树是 `for (const kind of KIND_ORDER)` 反查根目录渲染的，没列进 KIND_ORDER 的 kind 一行都不出现 —— 数据层（FIXED_FOLDERS / folderKinds / metadata）其实一直有，只是 UI 不画。
- 修复：KIND_ORDER 补 `'script'`（位置与 FIXED_FOLDERS 一致，控制器之后、角色之前）。
- 顺手清理：AssetBrowser 默认目录兜底写死 `'图片'`（早期改名前的老名字，永远不存在的路径）→ 改 `ROOT_NAMES[0]`。
- 探针加固：verify.ts 第三张探针新增 `hasScriptFolder`（左栏 folder-row title 里必须有「脚本」）+ `scriptTile`（点进脚本目录 → addScript → 右栏出现该脚本 tile），并切回贴图目录避免污染后续探针。结果 hasScriptFolder:true / scriptTile:true，shot 全绿。
- 教训：**新增 AssetKind / FolderKind 时必须同步 `KIND_ORDER`**，否则 UI 静默丢失整类资产；这类漏项 tsc 抓不到（Record 覆盖检查只在 KIND_LABEL 那种 Record 类型上生效）。
